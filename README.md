# FITREHAB NEXT — تطبيق لياقة عربي (PWA)

تطبيق ويب عربي RTL يشتغل بدون سيرفر ولا اشتراكات: مكتبة تمارين بفيديوهات توضيحية، تسجيل مجموعات (تكرار + وزن) مع مؤقت راحة تلقائي، تتبع تغذية وأهداف، تتبع وزن، سجل جلسات، ونسخ احتياطي JSON. كل الملفات محلية والبيانات في `localStorage`.

## التشغيل محليًا
```bash
python -m http.server 8000
```
افتح `http://localhost:8000` (الـ service worker محتاج http/https، مش `file://`).

## النشر على Vercel
Import للمشروع، Framework Preset = **Other**، بدون build command. ملف `vercel.json` فيه security headers وCSP.

## اللي اتصلح/اتكمل في v2
- **الموبايل:** الكروت كانت متضغطة في عمودين (المؤقت والأرقام كانت بتطلع بره) ← عمود واحد.
- **الأرقام:** `٠` كانت شبه نقطة ← أرقام لاتينية في كل التطبيق.
- **التمرين:** كان عداد مجموعات بس ← تسجيل كل مجموعة (تكرار/كجم)، إضافة وحذف تمارين، مؤقت راحة يبدأ تلقائيًا (30/60/90/120 ث) مع صوت واهتزاز وشريط عائم، وسجل بتفاصيل كل جلسة وحذفها.
- **التغذية:** أهداف سعرات وبروتين، شريط تقدم، التنقل بين الأيام، وجبات سريعة من الأخيرة، رسم 7 أيام.
- **التقدم:** تتبع الوزن (كان في الـ state من غير واجهة)، رسم بياني، سلسلة أيام متتالية.
- **الصور والفيديو:** اتشالت كلمة إنجليزية (LEGS/CHEST…) كانت مطبوعة جوه كل صورة وفيديو.
- **PWA:** أيقونات PNG (any + maskable + apple-touch) عشان التثبيت يشتغل، وservice worker جديد بيدعم Range requests للفيديو (Safari/iOS) وصفحة offline.
- **عام:** إدارة الفوكس في النافذة (Trap + استرجاع)، استيراد نسخ v1 القديمة، تحقق أقوى من الملفات المستوردة.

## حدود معروفة
- نموذج أولي ثابت: لا حسابات ولا مزامنة سحابية ولا Backend. البيانات على نفس الجهاز/المتصفح فقط (صدّر نسخة احتياطية).
- الفيديوهات رسوم تخطيطية أصلية (مش تصوير بشري)، والمحتوى تعليمي وليس نصيحة طبية.
- مكتبة التمارين 8 تمارين فقط؛ إضافة تمرين = سطر في `EX` داخل `app.js` + ملفي `media/<id>.png` و`.mp4`.
